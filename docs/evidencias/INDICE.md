# Evidencias fotográficas de CampusHub — Avance 1 (Semana 13)

Capturas originales facilitadas durante esta conversación, organizadas y recortadas para quitar la barra de tareas inferior de Windows cuando estaba visible. No se ha alterado el código ni se han inventado resultados.

## Cómo incorporar en VS Code

1. Extrae el ZIP.
2. Copia la carpeta `docs/evidencias` dentro de la carpeta principal `CampusHub_S13` (fusiona con `docs` existente).
3. Comprueba cuáles imágenes sirven como evidencia requerida por tu docente; las capturas de código son material de apoyo para la sustentación.
4. Si decides incluirlas en GitHub, revisa primero cualquier dato personal mostrado en pantallas, direcciones de rutas o nombres de usuario.
